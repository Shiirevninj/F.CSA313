# Exploratory Testing Charter

## Туршилтын объект
Уншлагын жагсаалт v2.0 веб апп

## Mission

**Судлах:**
Ном нэмэх, хайх, устгах, жагсаалт харуулах
үйлдлүүд болон API-ийн ажиллагааг судлах.

**Ашиглан:**
Хоосон болон буруу форматтай оролт,
давхардсан өгөгдөл, урт текст, том жижиг
үсгийн ялгаа, HTTP хүсэлтүүдийг ашиглан
Supermodel, Couch Potato, Saboteur
аяллуудаар тестлэх.

**Илрүүлэх:**
Оролтын баталгаажуулалт, өгөгдлийн бүрэн
бүтэн байдал, хайлтын ажиллагаа,
интерфейсийн харагдах байдал болон
API-ийн алдааны боловсруулалттай
холбоотой согогуудыг илрүүлэх.

## Сонгосон аяллууд

### 1. Supermodel — GUI

Хэрэглэгчийн интерфейсийн харагдах
байдал, товчны өнгө, хүснэгтийн
байрлал, урт текстийн нөлөөг шалгана.

Энэ апп нь номын мэдээллийг хүснэгтээр
харуулдаг тул интерфейсийн эвдрэл,
харагдах байдлын алдааг илрүүлэхэд
тохиромжтой.

### 2. Couch Potato — Хоосон оролт

Ном нэмэх талбаруудыг хоосон үлдээх,
зөвхөн зай оруулах, дутуу мэдээлэл
бөглөх зэрэг туршилт хийнэ.

Гарчиг, зохиолч, он гэсэн гурван талбар
заавал бөглөгдөх ёстой тул оролтын
баталгаажуулалтыг шалгахад тохиромжтой.

### 3. Saboteur — API

curl ашиглан буруу JSON болон
шаардлага хангахгүй POST хүсэлт
илгээж, серверийн HTTP статус болон
хариуг шалгана.

Спецификацийн дагуу буруу JSON
биетэй POST хүсэлтэд HTTP 400
буцаах ёстой тул API-ийн алдааны
боловсруулалтыг шалгахад тохиромжтой.

## Туршилтын хамрах хүрээ

- Заавал бөглөх талбарууд
- Он: 1000–2100 бүхэл тоо
- Давхардсан ном нэмэх
- Гарчиг, зохиолчийн хайлт
- Том, жижиг үсгийн ялгаа
- Устгах товчны өнгө
- Урт текстийн харагдах байдал
- Нийт номын тоолуур
- API-ийн буруу хүсэлтийн боловсруулалт

## Хүлээгдэж буй үр дүн

60 минутын exploratory session
гүйцэтгэж, илэрсэн согогуудыг
тэмдэглэн, дор хаяж 3 өөр согогийг
дахин гаргах алхам болон нотолгоотой
тайлагнах.

Үүнээс дор хаяж нэг нь API эсвэл
өгөгдлийн түвшний согог байна.
