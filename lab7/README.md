## Лабораторийн зорилго
Session-Based Test Management (SBTM) аргаар
"Уншлагын жагсаалт" веб аппыг судалж,
функциональ, интерфейс болон API түвшний
согогуудыг илрүүлж, нотолгоотой тайлагнах.

## Туршилтын объект
Багшийн өгсөн app.js файлыг ашигласан.
Апп нь Node.js орчинд ажилладаг бөгөөд
ном нэмэх, хайх, устгах болон номын
жагсаалт удирдах боломжтой.

## Ажлын үе шат
1. Туршилтын орчин бэлтгэх
2. Exploratory testing charter боловсруулах
3. 60 минутын exploratory session гүйцэтгэх
4. Session report болон bug report боловсруулах
5. Үр дүнг нэгтгэж, дүгнэлт гаргах

## Үр дүн ба дүгнэлт
Туршилтын session дууссаны дараа
энэ хэсэгт үр дүн болон Хэсэг E-ийн
дүгнэлтийг нэмнэ.
