### Эцсийн дүгнэлт

Энэхүү лабораторийн ажлаар Session-Based Test Management (SBTM) аргыг ашиглан веб аппликейшнд exploratory testing гүйцэтгэлээ. Туршилтын өмнө charter боловсруулж, шалгах хүрээ болон ашиглах аяллуудаа тодорхойлсон. Couch Potato аяллаар хоосон талбар, буруу он болон давхардсан өгөгдөлтэй холбоотой согогуудыг илрүүлсэн. Supermodel аяллаар устгах товчны өнгө, номын оны формат болон урт гарчгийн улмаас үүсэх интерфейсийн асуудлуудыг ажигласан. Saboteur аяллын хүрээнд API руу буруу өгөгдөл илгээхэд HTTP 400-ийн оронд HTTP 200 буцааж байгааг тогтоосон. Нийт есөн төрлийн боломжит согог тэмдэглэж, тэдгээрийн нэгийг дахин баталгаажуулах шаардлагатай гэж үзсэн. Хугацааны хязгаарлалтаас шалтгаалан бүх төрлийн оролт, олон хэрэглэгчийн зэрэгцээ ажиллагаа болон системийн ачааллыг бүрэн шалгаагүй. Playwright зэрэг автоматжуулалтын хэрэгсэл нь давтагдах тестүүдийг тогтмол гүйцэтгэхэд тохиромжтой бол exploratory testing нь урьдчилан төлөвлөөгүй асуудлыг илрүүлэхэд давуу талтай гэж үзэж байна. Мөн хэрэглэгчийн интерфейсийн харагдах байдал, ойлгомжтой байдлыг хүний ажиглалтаар үнэлэх нь чухал болохыг ойлгосон. Цаашид илэрсэн согогуудыг зассаны дараа дахин тест хийж, оролтын баталгаажуулалт, хайлт болон API-ийн алдааны боловсруулалтыг сайжруулах шаардлагатай гэж дүгнэсэн.
